## 실행방식(개발)
1. LifeMasterBeApplication로 실행합니다.
2. 실행 하기전, DOCKER Desktop 설치하시고, 미리 실행하셔야 자동으로 도커 컨테이너 환경 생성해서 실행합니다.
3. https://www.notion.so/2024-Seeds-aba6004bb19247aabfccba46a8a60db1?p=5d1a792db1d44916a9811ec000e59f39&pm=s 내용으로 application.properties 내용 수정합니다.
4. swagger UI 링크는 http://localhost:8080/swagger-ui/index.html 입니다.
